## 🧩 Troubleshooting

We want your Wisp experience to be flawless. Here are solutions to common issues:

### Wisp Won't Start
- Make sure you've downloaded the correct version for your Windows (64-bit vs 32-bit)
- Try right-clicking the downloaded file and selecting "Run as Administrator"
- Check if your antivirus software is blocking it - you may need to allow Wisp through

### Gauges Aren't Showing Data
- Verify that Forza Horizon 6 is running and you're in an actual race (not in the main menu)
- Make sure you haven't disabled UDP telemetry in the game's settings
- Restart both Forza and Wisp to re-establish the connection

### Overlay Looks Wrong
- Try resetting Wisp to default settings (check the system tray menu)
- Update your graphics card drivers to the latest version
- Check if your screen resolution is fairly standard - Wisp works best with common resolutions

### Game Performance Issues
- Close other background applications that might be using resources
- Lower Wisp's refresh rate in the settings if you notice any stuttering
- Make sure your system meets Forza Horizon 6's minimum requirements
